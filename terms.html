Finalidade do site

Este site apresenta o trabalho de Victor Saraiva, incluindo sites conceituais, aplicações frontend e APIs desenvolvidas para fins de demonstração e estudo. As informações descrevem o escopo conhecido de cada implementação.

Demonstrações e dados de exemplo

Northside Barber Co., Voltline Electrical e Smash & Co. são marcas fictícias. Endereços, contatos, preços, produtos, pessoas, avaliações e demais informações exibidos nesses projetos podem ser dados inventados para a demonstração. Não representam negócios, serviços, pedidos ou reservas reais.

AgendaFlow não cria reservas reais e seu painel não possui autenticação. TaskFlow armazena dados somente no navegador. A Task Management API mantém dados apenas em memória e os perde quando o processo reinicia. A GitHub Analytics API consulta dados públicos do GitHub e está sujeita à disponibilidade e aos limites desse serviço. Consulte a página de cada projeto para os detalhes e limitações.
