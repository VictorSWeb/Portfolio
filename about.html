Sobre / Victor Saraiva

Aprender construindo software.

Sou Victor Saraiva e uso projetos práticos para estudar desenvolvimento web, interfaces e serviços backend.

O que exploro

Tenho trabalhado com HTML, CSS, JavaScript, TypeScript, React, Next.js e Python. Os projetos deste portfólio incluem páginas para negócios fictícios, aplicações que mantêm dados no navegador e APIs que validam entradas ou consultam serviços externos.

O foco é entender como as partes se conectam: apresentar informação, organizar estado, validar dados e tornar os limites de cada implementação claros.

Como ler os projetos

Sites conceituais são exercícios de interface e conteúdo para marcas inventadas. Os projetos de software têm páginas próprias com tecnologias, recursos disponíveis, links de código e limitações de execução. Demos e serviços externos podem ficar indisponíveis ou mudar.

Quando um projeto usa LocalStorage, memória do processo ou a API pública do GitHub, isso é indicado na respectiva página. Nenhuma demonstração deve ser interpretada como serviço de produção.

Próximos passos

Continuo aprimorando fundamentos de frontend e backend por meio de implementação, documentação e testes. Para conversar sobre uma oportunidade ou um projeto, use a página de contato.
