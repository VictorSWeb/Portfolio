Projeto 06 / API REST

Task Management API

API REST para criar, consultar, atualizar e excluir tarefas. A implementação separa rotas, controladores, serviços e repositório, valida entradas e expõe documentação interativa.

Runtime
Node.js · Express
Linguagem
TypeScript
Validação
Zod
Testes
Vitest

Rotas principais

  • GET/api/health
  • GET/api/tasks
  • GET/api/tasks/:id
  • POST/api/tasks
  • PUT/api/tasks/:id
  • DELETE/api/tasks/:id

Os registros ficam somente em memória no processo da API. Eles são perdidos quando o servidor reinicia e não são compartilhados entre instâncias.

Consultas e validação

A listagem aceita filtros por status e prioridade, busca sem distinção entre maiúsculas e minúsculas no título, ordenação e paginação. Os parâmetros e corpos das requisições são validados com Zod.

Os endpoints e esquemas estão documentados por Swagger UI e OpenAPI. O projeto não implementa autenticação, autorização ou persistência durável.
