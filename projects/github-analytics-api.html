Projeto 07 / API REST

GitHub Analytics API

API assíncrona em Python que consulta a API REST pública do GitHub para exibir perfis, listar repositórios e calcular estatísticas. O uso básico não exige token; os dados refletem o momento da consulta.

Runtime
Python 3.11+
API
FastAPI · Pydantic
HTTP
HTTPX assíncrono
Testes
Pytest · AnyIO

Endpoints

  • GET/api/health
  • GET/api/v1/users/{username}/profile
  • GET/api/v1/users/{username}/repositories?page=1&per_page=10&sort=updated&direction=desc
  • GET/api/v1/users/{username}/summary

O resumo agrega estrelas, forks, repositórios originais e forks, distribuição de linguagens, repositório mais estrelado e atualização mais recente.

Completude e limites

O endpoint de resumo consulta todas as páginas esperadas, confere a contagem com o perfil e verifica IDs únicos e paginação final. Ele sinaliza estatísticas completas; dados inconsistentes ou paginação incompleta geram erro em vez de um total parcial apresentado como completo.

O resumo aceita até 5.000 repositórios públicos. Acima desse limite, retorna erro. A consulta também está sujeita ao limite de requisições não autenticadas do GitHub; uma análise de perfil grande consome várias chamadas.

Repositórios privados não são acessíveis. O GitHub não oferece um retrato atômico entre páginas, então alterações ocorridas durante a consulta ainda podem afetar a consistência temporal.

A API não usa banco de dados nem autenticação própria. As estatísticas são calculadas com dados públicos do GitHub disponíveis durante cada solicitação.

Código e documentação

Os testes usam transporte HTTP simulado e não dependem de internet ou token. O README inclui instalação, execução local, exemplos curl, documentação OpenAPI e comportamento de erros.
