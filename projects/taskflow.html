Projeto 04 / Aplicação frontend

TaskFlow

Aplicação de gerenciamento pessoal de tarefas. Permite organizar itens por status e prioridade, acompanhar um resumo e manter os dados no navegador utilizado.

Interface
React · TypeScript
Ferramentas
Vite · CSS
Persistência
LocalStorage
Servidor
Não utilizado

Recursos

  • Criar, editar, excluir e alterar o status de tarefas.
  • Definir prioridade e data opcional de vencimento.
  • Pesquisar por título e descrição, filtrar por status e prioridade, e ordenar por criação, vencimento ou prioridade.
  • Consultar totais e contagens de tarefas por status.
  • Exibir um aviso quando o navegador não consegue ler ou gravar os dados locais.

Armazenamento e limites

As tarefas são guardadas no LocalStorage sob a chave taskflow.tasks.v1. Permanecem no mesmo navegador e na mesma origem entre recarregamentos.

Os dados não são enviados a um servidor e não são sincronizados entre navegadores ou dispositivos. A aplicação não tem backend, banco de dados, autenticação ou colaboração entre usuários.

Código-fonte

O repositório inclui instruções para instalar dependências, iniciar o ambiente local, executar o build e rodar o ESLint.
