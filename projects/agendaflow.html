Projeto 05 / Demonstração frontend

AgendaFlow

Uma demonstração de agendamento para a NorthSide Barber Co., marca fictícia. O projeto reúne um fluxo público de reserva de exemplo e ferramentas administrativas para explorar serviços, profissionais e horários.

Interface
Next.js · React · TypeScript
Estilos
Tailwind CSS
Dados
Exemplos estáticos e LocalStorage
Backend
Não implementado

O que dá para explorar

  • Fluxo público de seis etapas para escolher serviço, profissional, data, horário e informar dados de demonstração.
  • Painel administrativo com visão geral de exemplo e gerenciamento local de agendamentos, profissionais e serviços.
  • Busca e filtros de agendamentos, além de ações para confirmar ou cancelar registros de exemplo.
  • Formulários para criar, editar, ativar e remover profissionais e serviços no navegador atual.

Limites da demonstração

O fluxo público usa datas, horários, serviços e profissionais estáticos. Concluir o fluxo não cria nem salva um agendamento real. Os indicadores do painel também são exemplos estáticos.

Alterações administrativas ficam no LocalStorage do navegador atual e não são sincronizadas com o fluxo público ou com outros dispositivos. O painel não possui backend, banco de dados ou autenticação e pode ser acessado publicamente.

A barbearia e seus dados são fictícios. Este projeto não aceita reservas reais.
